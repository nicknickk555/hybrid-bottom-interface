# Hybrid Bottom — Controlled Root Interface

Hybrid Bottom combines three technical layers:

- a Typar transfer and timing membrane;
- three mirrored Venturi zones (D1 centre, D2 transition, D3 periphery);
- an Air‑Bag cavity that renews the boundary layer below the container.

The public GitHub Pages story is intentionally reduced to three screens:

1. **Concept** — why the bottom is the missing root interface.
2. **Architecture** — root approach, Typar contact, local micro-drying, apex pruning and lateral branching.
3. **Model** — comparative tuning by climate, Typar grade, airflow mode, humidity and Air‑Bag clearance.

## GitHub Pages

Source files live in `github-pages-src/`. Build the publishable `docs/` folder with:

```bash
npm run pages:build
```

The diagram contains no visible embedded text and supports `prefers-reduced-motion`.

## Application build

The repository also retains its vinext application surface:

```bash
npm install
npm run build
```

The calculation is a comparative engineering model. Physical validation is required before production specification.
